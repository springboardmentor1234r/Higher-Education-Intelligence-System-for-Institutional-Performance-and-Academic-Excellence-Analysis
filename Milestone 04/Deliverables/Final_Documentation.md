# Final Project Documentation — EduVision_DV

## Overview
EduVision_DV is a comprehensive business intelligence system evaluating world university rankings, research excellence, student demographics, and national education trends.

## Core Features
1. **Four Interconnected Dashboards:** University Overview, Research Analytics, Student Analytics, Country Comparison.
2. **Interactive Navigation:** Native button-driven navigation allowing users to traverse dashboards seamlessly.
3. **Audited Hyper Extract Engine:** Packaged with full 58-column extract supporting Tableau Public cloud publishing.
