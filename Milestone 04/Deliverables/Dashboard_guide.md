# EduVision_DV — Dashboard User Guide & Reference

## Navigation Architecture
EduVision_DV provides two persistent navigation systems across all dashboards:
1. **Left Navigation Sidebar:**
   - 🎓 University Overview (`University Overview`)
   - 🔬 Research Analytics (`Research Analytics`)
   - 👩‍🎓 Student Analytics (`Student Analytics`)
   - 🌍 Country Comparison (`Country Comparison`)
2. **Top Quick-Jump Navigation Bar:**
   - Single-click shortcuts located at the top-right header for rapid view switching.

## Interactivity & Filtering
- **Country Filter:** Select any country to isolate institutional metrics; choose `(All)` for global context.
- **Dynamic Tooltips:** Hover over any visualization mark to view underlying institutional metadata, raw scores, and ranks.
