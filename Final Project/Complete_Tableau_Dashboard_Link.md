# EduVision_DV — Complete Tableau Dashboard Link & Access Guide

## Project Deliverable Overview
EduVision_DV is an executive higher education analytics suite consisting of four unified, interlinked interactive dashboards built in Tableau Desktop and Tableau Public.

---

## 1. Tableau Public Interactive Links
- **Interactive Dashboard Suite**: [EduVision_DV on Tableau Public](https://public.tableau.com/app/profile/chaitanya.teppa) *(or publish via File -> Save to Tableau Public in Tableau Desktop)*
- **Offline Tableau Packaged Workbook**: Available directly in this repository at [`Milestone 3/Module 6/EduVision_DV.twbx`](../Milestone%203/Module%206/EduVision_DV.twbx) and [`Milestone 3/Book2.twb`](../Milestone%203/Book2.twb).

---

## 2. Included Interlinked Dashboards

| # | Dashboard Name | Primary Analytical Focus | Key Features |
| :---: | :--- | :--- | :--- |
| **1** | **University Overview** | Global Rankings & Institutional Landscape | Top 10 rankings, country institution breakdown, academic reputation vs. overall score, 4 executive KPI cards |
| **2** | **Research Analytics** | Scholarly Impact & Citation Velocity | Tri-panel bar charts (Research Impact, Citations per Faculty, Productivity Index), single-university cross-chart enlargement (`entire-view`), 4 research KPIs |
| **3** | **Student Analytics** | Student Demographics & Diversity | Global international student share, Top 10 enrollment by country, faculty-to-student ratios, fully responsive bi-directional actions |
| **4** | **Country Comparison** | National Higher Education Benchmarking | 4 country comparison charts, single-country isolation on click, dynamic re-aggregation of national metrics |

---

## 3. How to Run Locally

1. Open Tableau Desktop (v2020.4 or newer).
2. Open either [`EduVision_DV.twbx`](../Milestone%203/Module%206/EduVision_DV.twbx) (standalone packaged with dataset extract) or [`Book2.twb`](../Milestone%203/Book2.twb).
3. Use the top navigation bar (`OVERVIEW`, `RESEARCH`, `STUDENTS`, `COUNTRIES`) to move between dashboards seamlessly.
4. Interact with any chart to test cross-dashboard context filtering and drill-down capabilities.
