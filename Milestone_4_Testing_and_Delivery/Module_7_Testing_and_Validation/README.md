# Module 7: Testing and Validation

## Objective
Validate the EduVision dashboard suite and its data pipeline.

## Testing Activities
- Validate source and processed datasets.
- Verify KPI calculations.
- Test Year, Region, and Country filters.
- Test navigation across all four dashboards.
- Check missing values and unknown geographic locations.
- Review dashboard readability and usability.

## Deliverables
- QA Checklist
- Dashboard Testing Report
- Data Validation Results
- Defect Log and Resolution Records

## Acceptance Criteria
- KPI calculations are verified.
- Dashboard filters and navigation are tested.
- Data-quality issues are documented.
- Test results and unresolved issues are recorded.

## Status
Testing results must be added after validation.
