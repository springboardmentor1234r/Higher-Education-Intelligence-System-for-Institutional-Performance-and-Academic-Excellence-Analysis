## Overview

**Milestone 5** serves as the executive submission package consolidating all verified deliverables from the EduVision_DV project. It brings together the production-ready Tableau workbooks, high-resolution dashboard screenshots, complete technical documentation reports, and the executive PowerPoint presentation for final evaluation.

---

## Delivered Artifacts in Milestone 5

### 1. Production Tableau BI Suite
- **`EduVision_DV.twbx`**: The unified, audit-compliant Tableau workbook containing all 4 interconnected dashboards with bidirectional filter actions, parameter controls, and custom dark-themed visual containers.
- **`eduvision_dashboard_v1.twbx`**: Baseline visual build (Dashboards 1 & 2).
- **`eduvision_prototype.twbx`**: Initial low-fidelity interactive prototype.

### 2. High-Resolution Dashboard Screenshots
- **`dashboard_1_university_overview.png`**: Scorecard showing global rankings, reputation vs. overall score, and choropleth geographic distribution.
- **`dashboard_2_research_analytics.png`**: Research productivity index, citation velocity, and regional collaboration quadrants.
- **`dashboard_3_student_analytics.png`**: Campus diversity, actual faculty-to-student ratios, and gender breakdowns.
- **`dashboard_4_country_comparison.png`**: Macroeconomic policy benchmark comparing national public education expenditure (% GDP) against university performance.

### 3. Master Project Documentation
- **`final_documentation.pdf`**: Comprehensive, publication-ready PDF documentation report.
- **`final_documentation.md`**: Complete Markdown documentation covering system architecture, ETL pipeline, and analytical findings.
- **`dashboard_storyboard.pdf`**: Visual storyboard detailing dashboard wireframes, layout containers, and user flows.
- **`dashboard_guide.md`**: User guide and navigation instructions for the Tableau dashboard suite.
- **`cleaning_methodology.md`**: Technical report on deterministic entity normalization and regex acronym resolution.
- **`kpi_definitions.md`**: Mathematical derivations and formulas for the 6 Higher Education KPIs.
- **`data_dictionary.md`**: Complete column-level data dictionary for the relational Star Schema.
- **`dataset_sources.md`**: Lineage and authority details for QS 2025, THE 2024, WUR 2023, and World Bank EdStats.

### 4. Executive Presentation Deck
- **`EduVision_DV_Project_Presentation.pptx`**: 19-slide widescreen PowerPoint presentation detailing the project background, data pipeline, Star Schema, KPI derivations, dashboard architecture, automated QA results, and analytical conclusions.
