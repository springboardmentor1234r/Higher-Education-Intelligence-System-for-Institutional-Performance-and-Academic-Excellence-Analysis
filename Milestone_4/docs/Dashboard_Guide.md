# EduVision_DV Dashboard Guide

## 1. Introduction

EduVision_DV is a Higher Education Intelligence System developed to analyze
university performance using data from global university rankings and
education-related datasets.

The Tableau dashboard provides interactive analysis of university,
research, student, and country-level performance.

---

## 2. Dashboard Overview

The EduVision_DV Tableau workbook contains four interactive dashboards:

1. University Overview
2. Research Analytics Dashboard
3. Student Analytics Dashboard
4. Country Comparison Dashboard

The dashboards are connected through interactive filters and navigation
buttons.

---

## 3. University Overview

The University Overview dashboard provides a summary of university
performance.

### Key Performance Indicators

- Academic Reputation Score
- Global Ranking Score
- International Student Percentage
- Research Impact Score
- Faculty-Student Ratio
- Research Productivity Index

### Filters

The dashboard provides filters for:

- Region
- Overview Year
- Country Name
- University Name

### Visualization

The University Ranking Comparison chart allows users to compare universities
based on their average Global Ranking Score.

---

## 4. Research Analytics Dashboard

The Research Analytics dashboard focuses on research-related university
performance.

### Key Performance Indicators

- Research Productivity
- Research Impact

### Visualizations

- Research KPI Comparison
- Research Impact Trend
- Research Productivity comparison

### Filters

- Country Name
- University Name
- Research Year

The dashboard allows users to examine differences in research performance
between universities.

---

## 5. Student Analytics Dashboard

The Student Analytics dashboard focuses on student-related indicators.

### Key Indicators

- Faculty-Student Ratio
- International Student Percentage
- Academic Reputation

### Visualizations

- Student Analytics comparison
- Academic Reputation comparison

### Filters

- Student Year
- Country Name
- University Name

The dashboard can be used to compare student-related indicators across
universities.

---

## 6. Country Comparison Dashboard

The Country Comparison dashboard provides country-level comparison of
higher education performance.

### Filters

- Country Name
- Overview Year
- Region

The dashboard helps users compare higher education performance across
different countries and regions.

---

## 7. Dashboard Navigation

Navigation buttons are provided within the dashboards to move between:

- University Overview
- Research Analytics
- Student Analytics
- Country Comparison

Users can select a dashboard navigation button to move directly to the
required analysis.

---

## 8. Using Filters

To use a filter:

1. Select the required filter.
2. Choose a value from the available options.
3. The relevant charts and KPI values update according to the selected
   criteria.
4. Select "All" to remove the filter selection.

The University Name filter can be used to examine the performance of an
individual university across the relevant dashboards.

---

## 9. Interactive Dashboard Analysis

The dashboard supports interactive analysis through filters and
cross-dashboard navigation.

For example, selecting a university on the University Overview dashboard
can be used to examine corresponding research and student-related
information.

---

## 10. Recommended Usage

For a complete analysis, users can follow this sequence:

1. Start with University Overview.
2. Select a region, country, year, or university.
3. Review the KPI values.
4. Navigate to Research Analytics to examine research performance.
5. Navigate to Student Analytics to examine student-related indicators.
6. Use Country Comparison to compare country-level performance.

---
