# EduVision_DV - Milestone 4

## Higher Education Intelligence System

Milestone 4 contains the final Tableau dashboard, project documentation, methodology, KPI definitions, testing report, and quality assurance checklist.

### Project Dashboards

The EduVision_DV project contains four interactive Tableau dashboards:

1. University Overview
2. Research Analytics Dashboard
3. Student Analytics Dashboard
4. Country Comparison Dashboard

### Folder Structure

- `dashboard/` - Final Tableau packaged workbook
- `docs/` - Dashboard documentation and project methodology
- `testing/` - Dashboard testing and QA documentation

### Final Deliverable

The final Tableau dashboard is provided as a packaged Tableau workbook (`EduVision_DV.twbx`) in the dashboard folder.
