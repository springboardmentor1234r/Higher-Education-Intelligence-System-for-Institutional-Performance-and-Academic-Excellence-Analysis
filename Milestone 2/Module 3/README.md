# Module 3: Education KPI Engineering

## Objectives:
- Engineer 6 defensible higher education KPIs:
  1. Global Ranking Score
  2. Research Impact Score
  3. Faculty-to-Student Ratio
  4. International Student Percentage
  5. Academic Reputation Score
  6. Research Productivity Index
- Construct a multi-sheet relational data model in Excel for Tableau.

## Deliverables:
- `generate_education_kpis.py`: Python KPI generation script.
- `university_final_dataset.xlsx`: Final multi-sheet workbook (`final_kpi_dataset`, `dim_university`, `dim_country`).
