# Higher-Education-Intelligence-System-for-Institutional-Performance-and-Academic-Excellence-Analysis
=======


##  Project Overview

This project focuses on analyzing higher-education institutional data to understand university performance, rankings, academic excellence, and related indicators.

The project uses data from QS 2024 and Times Higher Education (THE) 2024 datasets and applies Python-based data collection, cleaning, and exploratory data analysis techniques.

## Objectives

- Collect higher-education ranking datasets.
- Clean and preprocess raw university data.
- Handle missing and inconsistent values.
- Explore important institutional performance indicators.
- Prepare a reliable dataset for further analysis and visualization.
