# EduVision_DV — Higher Education Performance Analytics

## Project Overview

**EduVision_DV** is a higher education performance analytics project that
integrates university ranking, research, student, and country-level education
data into interactive Tableau dashboards.

The project uses data from:

- QS World University Rankings 2025
- Times Higher Education World University Rankings 2024
- World University Rankings 2023
- World Bank Education Statistics

## Milestone 3 — Dashboard Development & Integration

Milestone 3 focuses on the development and implementation of the four
interactive Tableau dashboards using the final analytical dataset.

The completed dashboards are:

1. University Overview
2. Research Analytics
3. Student Analytics
4. Country Comparison

The dashboards are integrated into a single Tableau workbook to provide
different levels of higher education performance analysis.

---

# Module 5 — University and Research Analytics

Module 5 focuses on university-level performance and research analytics.

## Dashboard 1 — University Overview

### Purpose

The **University Overview** dashboard provides a high-level view of
university performance, rankings, academic reputation, research impact,
faculty-student ratio, and international student representation.

### Key KPIs

- Global Rank
- Overall Score
- Academic Reputation
- Research Impact
- Faculty-Student Ratio
- International Students %

### Visualizations

- Top Universities
- Universities by Region
- Academic Reputation
- University Performance Trend

### Dashboard Controls

- Year
- Region

The dashboard provides an overview of university performance and allows
users to examine ranking and performance information across different
years and regions.

---

## Dashboard 2 — Research Analytics

### Purpose

The **Research Analytics** dashboard focuses on research performance and
provides analytical comparisons between universities and regions.

### Key KPIs

- Research Score
- Citation Score
- Research Impact
- Research Productivity

### Visualizations

- Research Impact Comparison
- Top Research Institutions
- Research Score Analysis
- Research Productivity Trends
- Citation Performance

### Dashboard Controls

- Year
- University
- Country

The dashboard allows users to examine research performance and compare
research-related metrics across institutions and regions.

# Module 6 — Student and Country Analytics

Module 6 focuses on student-related analytics and country-level education
performance.

## Dashboard 3 — Student Analytics

### Purpose

The **Student Analytics** dashboard analyzes student population,
internationalization, faculty-student relationships, and enrollment
patterns.

### Key KPIs

- Total Students
- International Students %
- Faculty-Student Ratio
- International Student Score
- Faculty Student Score

### Visualizations

- Student Diversity Trends
- International Student Analysis
- Faculty-to-Student Ratio Analysis
- Enrollment Comparison
- Student Distribution Analysis

### Dashboard Controls

- Year
- University

The dashboard provides an analytical view of student demographics,
enrollment, international student representation, and faculty-student
relationships.

---

## Dashboard 4 — Country Comparison

### Purpose

The **Country Comparison** dashboard provides country-level analysis of
education performance and compares countries using education-related
indicators.

### Key KPIs

- Total Countries
- Education Countries
- Average Literacy
- Average Tertiary Enrollment

### Visualizations

- Regional Education Comparison
- Country Ranking Comparison
- Education Performance Benchmarking
- Top Performing Countries

### Dashboard Controls

- Country
- Region

The dashboard allows users to compare countries using literacy,
tertiary enrollment, education performance, and ranking-related metrics.

# Dashboard Integration

The four dashboards are integrated into a single Tableau dashboard system.

The navigation structure is:

```text
University Overview
        ↓
Research Analytics
        ↓
Student Analytics
        ↓
Country Comparison
````

Users can navigate between the four dashboard views using the integrated
dashboard navigation.

The dashboards use the final analytical data model developed during
Milestone 2.

The integrated Tableau workbook provides a unified interface for analyzing:

* University performance
* Research performance
* Student analytics
* Country-level education performance
