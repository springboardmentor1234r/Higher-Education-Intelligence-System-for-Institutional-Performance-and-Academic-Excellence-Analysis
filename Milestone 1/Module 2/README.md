# Module 2: Data Cleaning & Transformation

## Objectives:
- Eliminate duplicate institutional records.
- Standardize university names and country names to ISO 3166-1 alpha-2 standards.
- Differentiate unranked missing values from true zeros.
- Coerce ranking metrics and calculate master IDs (`university_id`, `country_id`).

## Deliverables:
- `education_cleaning.ipynb`: Comprehensive Jupyter notebook executing the ETL pipeline.
- `university_cleaned.csv`: Cleaned Tableau-ready dataset with 2,517 global universities.
