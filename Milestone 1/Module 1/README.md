# Module 1: University Data Collection

## Objectives:
- Ingest raw QS World University Rankings 2025 and THE World University Rankings 2024.
- Select relevant educational and research performance indicators.
- Create initial match keys without aggressive fuzzy matching.
- Generate `university_raw_data.csv`.

## Deliverables:
- `data_collection.py`: Automated ingestion and integration script.
- `university_raw_data.csv`: Merged raw dataset with >95% completeness.
