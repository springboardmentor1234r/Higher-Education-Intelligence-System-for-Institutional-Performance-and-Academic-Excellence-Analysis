The following six KPIs were validated:

1. Global Ranking Score
2. Research Impact Score
3. Faculty-to-Student Ratio
4. International Student Percentage
5. Academic Reputation Score
6. Research Productivity Index

All six KPI sheets were created and tested in Tableau.

- Dashboard values were compared with the prepared dataset.
- No major data display issues were identified.
