# Education Analytics Methodology

## 1. Project Overview

EduVision DV is an education analytics project developed to analyze university performance using ranking, research, academic, and student-related metrics.

The analysis was implemented using Python for data preparation and Tableau for visualization and dashboard development.

## 2. Data Preparation

The university dataset was prepared and cleaned before being used for dashboard development.

The data contains information related to:

- University names
- Countries
- Global ranking
- Academic reputation
- Research performance
- Faculty and student information
- International students
- Citations and research metrics

## 3. KPI Engineering

Six major KPIs were developed for the project:

1. Global Ranking Score
2. Research Impact Score
3. Faculty-to-Student Ratio
4. International Student Percentage
5. Academic Reputation Score
6. Research Productivity Index

These KPIs were prepared for analysis and visualization in Tableau.

## 4. Tableau Visualization

Tableau was used to create interactive visualizations and dashboards.

The project contains four main dashboards:

- University Overview Dashboard
- Research Analytics Dashboard
- Student Analytics Dashboard
- Country Comparison Dashboard

## 5. University Analysis

University-level analysis was performed using ranking, research impact, research productivity, and citation-related metrics.

This allows users to explore and compare university performance.

## 6. Country Analysis

Country-level analysis was performed to compare:

- Number of universities
- Average ranking performance
- Research impact
- Academic reputation

This provides a country-level view of higher education performance.

## 7. Student Analysis

Student-related analysis includes:

- International student percentage
- Faculty-to-student ratio
- Female-to-male student ratio

These metrics help analyze student diversity and faculty availability.

## 8. Research Analysis

Research analysis focuses on:

- Research Impact Score
- Research Productivity Index
- Research Citations

These metrics are visualized to compare research performance between universities.

## 9. Dashboard Interaction

Tableau filters and dashboard interactions allow users to explore the data dynamically.

Users can select universities and explore different dimensions of higher education performance.

## 10. Testing and Validation

The dashboards and KPI calculations were tested before final delivery.

Testing included:

- KPI validation
- Ranking validation
- Dashboard functionality
- Filters
- Charts
- Tooltips
- Dashboard navigation

No major dashboard issues were identified during final testing.

## 11. Final Output

The final project consists of four interactive Tableau dashboards supported by KPI calculations, data preparation, testing documentation, and project documentation.

The project is intended to provide a portfolio-ready higher education analytics solution.
