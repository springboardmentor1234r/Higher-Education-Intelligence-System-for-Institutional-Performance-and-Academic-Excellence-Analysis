# Milestone 3: Dashboard Development (Weeks 5–6)

This folder contains the complete interactive Tableau dashboard suite for EduVision_DV.

## Deliverables:
1. `eduvision_dashboard_v1.twbx` (Module 5):
   - **Dashboard 1: University Overview** (6 KPI cards, Top 10 Ranked Universities, Regional Donut chart, Score trends).
   - **Dashboard 2: Research Analytics** (Citations vs Research Scatter plot, Top institutions by Research Productivity Index).

2. `EduVision_DV.twbx` (Module 6 - Final Unified Suite):
   - **Dashboard 3: Student Analytics** (International student % map, Faculty-to-student ratio by region, Gender diversity breakdown).
   - **Dashboard 4: Country Comparison** (Global university density, National performance benchmarking).
   - **Integrated Navigation:** Global top navigation buttons and dynamic filter actions linking `university_id` and `country_id`.
